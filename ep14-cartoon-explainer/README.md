# Ep 14 - AI cartoon explainer videos (3.8M views style)

The recipe behind "Why Did Humans Start Wearing Clothes?": a big question, three clues with real numbers, simple
stick-figure cartoon pictures that change every two to three seconds, and one fast voice. No video clips, no music.
We make the same story with AI, with a source for every number.

## Files
| Step | File | What it does |
|---|---|---|
| 1 | [01_cartoon_explainer_writer.md](01_cartoon_explainer_writer.md) | System prompt: facts first, the story shape, the narration, character sheets, picture prompts that each start with their own tag. |
| 2 | [02_pictures_voice_slideshow.md](02_pictures_voice_slideshow.md) | The voice, every image-page and slideshow setting with the reason, the problems we hit and the fixes. |
| 3 | [03_clothes_fact_list_with_sources.md](03_clothes_fact_list_with_sources.md) | The original's 35 claims, graded and sourced. |

## The rest of the recipe
4. One narration line = one picture = one subtitle line (pictures and subtitle lines must be the same number).
5. Run 1: the character sheets (one figure per panel, drawn large). Run 2: all pictures, each tagging its sheets.
6. Slideshow: one picture per subtitle line, the voice, 16:9 crop, pan left/right and zoom in/out.

## What we measured in the original
- 8:14, 3.82M views; 181 pictures, median 2.4 s, still 70% of the time; one voice at about 165 words a minute, no music.
- The channel: 34 videos in under 3 months, 119 subscribers, median about 2,300 views; this one is the outlier.
