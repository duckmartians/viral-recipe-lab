# First frames, 8-second clips and the join (baby + big food ASMR)

## 1. First frames (one image per clip)
Use the IMAGE lines from file 1 in any image model (16:9). Keep the setting and look sentences word for word in every
image, so all the frames look like one set. Save each image under its tag: `bbcroissant.jpg`, `bbdonut.jpg`...
Check every image before you spend video credits: the big food on the left, ONE baby on the right, the baby clearly
made of the food (crust, glaze, seeds), nothing else on the surface.

For a closing clip with several babies, make its own first frame (`bbtray.jpg`) with every baby described: a closing
clip described only in words came back as five breads, not five babies.

## 2. Clips (8 seconds each)
- A video model that takes the image as a reference ("ingredients", Omni) or as a first frame. Put all the images in
  one folder and point the tool to it; each `@tag` in a prompt pulls in its image.
- Duration tag `[8s]` in every prompt (6 s for an opening shot without babies).
- Run 5 at a time with no delay between rows if your accounts allow it; the clips do not depend on each other.
- Watch every clip: the baby must stay one baby, stay sitting, and the action must be the one you asked for.

## 3. Join
No editing: put the clips back to back in your order, hard cuts every 8 seconds, keep the clip sound, no music, no
captions. 12-18 clips = 1:30 to 2:30. Name the video like the series and make many versions: the original channel
has 105 videos with almost the same title; most get about 22K views and one got 72M.

## 4. Problems we hit making the sample (and the fix)
| Problem | Fix |
|---|---|
| First version with breads: every clip beige and brown, "looks like the same clip twelve times" | Back to fruit, only fruits the original did not use, ordered so the colour changes every clip, on a bright marble counter |
| The closing clip ("five babies on a tray", words only) came back as five breads with no faces | Its own first frame with every baby described, then the clip starts from it |
| The big watermelon slice vanished in the last 2 seconds | "Nothing disappears: the big fruit stays in the same place for the whole clip, only a bite may be missing" |
| The cherry baby turned into a human baby face at the end | "glossy dark red cherry from head to toe for the whole clip", and a simpler action (one bite) |
