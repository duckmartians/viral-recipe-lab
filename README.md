# Viral Recipe Lab

Free prompt files from the **Viral Recipe Lab** YouTube channel.

We take apart viral AI videos, write down the recipe (story, style, pacing), and show you how to make your own
version step by step. Every episode gets its own folder with the exact prompts used in the video.

| Episode | Recipe | Files |
|---|---|---|
| 01 | "Ink Explainer" history videos (stick-figure explainers, one still image every ~2 s) | [ep01-ink-explainer](ep01-ink-explainer) |
| 02 | "The ENTIRE History of X" epics (one repeating idea, a cast in costumes, ~2.6 s per image) | [ep02-entire-history](ep02-entire-history) |
| 03 | 3D reconstructions of real events (source-graded dossier, clay 3D scenes written as code) | [ep03-reconstruction](ep03-reconstruction) |
| 04 | AI dialogue dramas with talking characters (reversal story, fixed cast, shot-list prompts) | [ep04-ai-dialogue-drama](ep04-ai-dialogue-drama) |
| 05 | Easy English listening stories (A2 cartoon family, "talk, then show" pacing) | [ep05-easy-english-story](ep05-easy-english-story) |
| 06 | Fruit-head family stories (Slow English cartoon, "show, barely tell") | [ep06-fruit-family-story](ep06-fruit-family-story) |

## How to use
1. Open the episode folder and copy the prompt file into your AI chat (Claude, ChatGPT, Gemini...).
2. Fill in the `{PLACEHOLDERS}`.
3. Follow the video for the image, voice and editing steps. Any tools work.

Free to use for your own videos.
