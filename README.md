# Viral Recipe Lab

Free prompt files from the **Viral Recipe Lab** YouTube channel.

We take apart viral AI videos, write down the recipe (story, style, pacing), and show you how to make your own
version step by step. Every episode gets its own folder with the exact prompts used in the video.

## How to use
1. Open the episode folder and copy the prompt file into your AI chat (Claude, ChatGPT, Gemini...).
2. Fill in the `{PLACEHOLDERS}`.
3. Follow the video for the image, voice and editing steps. Any tools work.

Free to use for your own videos.
